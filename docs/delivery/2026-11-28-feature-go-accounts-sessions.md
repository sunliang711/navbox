# 账户与会话功能交付

## 业务范围

管理后台通过“账户与会话”管理当前账号的密码、设备会话以及控制台账号。账号分为管理员与只读两种角色。管理员能够创建账号、修改用户名、切换角色、启用和停用账号，以及重置账号密码。账号管理操作要求输入操作者自己的当前密码。

只读账号能够查看网站、标签、定时任务和审计数据，修改自己的密码并注销自己的会话。业务写操作、配置导入导出以及凭据查看要求管理员角色。权限同时受到页面控制和服务端验证。

## 会话与安全规则

活跃会话展示登录 IP、浏览器信息、最后活跃时间、过期时间和当前会话标记。会话列表仅展示当前账号未过期的会话。注销当前会话需要确认，操作成功后退出登录。最近活跃记录以一分钟为写入间隔，滑动续期沿用现有有效期配置。

修改自己的密码会注销本账号的其他设备会话。管理员重置其他账号密码会注销目标账号的全部会话；重置自己密码时保留当前会话。角色变更和停用操作会注销目标账号会话。系统至少保留一个启用的管理员，当前登录账号不能停用自己。

账号管理、密码变更、登录及数据迁移在事务中处理，并使用数据库行锁串行化，保证并发操作不会移除最后一个可用管理员。会话令牌只保存摘要；接口响应和账号变更审计均不包含密码或令牌摘要。审计记录包含操作者的账号标识与用户名。

## 数据兼容与部署

数据库启动迁移负责维护账号与会话字段。单管理员数据对应默认用户名 admin，沿用原有密码摘要并接管未过期会话。迁移具有幂等性。历史会话没有记录的 IP 和浏览器信息保持未知，后续登录记录完整来源信息。

主账号具有稳定身份标记。密码恢复模式即使在主账号改名、降级或停用后，仍能恢复该账号的密码、管理员角色与启用状态，同时注销全部账号会话。主账号名称保持用户设定值。

部署不需要额外配置项或依赖。数据库迁移、账号兼容处理和应用更新在同一发布窗口完成。

## 接口

账号登录使用用户名和密码。会话检查返回当前账号身份。活跃会话通过 GET /api/v1/admin/sessions 查询，并通过 DELETE /api/v1/admin/sessions/:id 注销。账号管理通过 GET、POST /api/v1/admin/accounts 与 PUT /api/v1/admin/accounts/:id 提供。账号变更请求的 current_password 为操作者自己的密码。

## 验证

验证覆盖 Go 全量回归、前端类型检查与生产构建、真实 PostgreSQL 旧表迁移、会话和账号接口、只读权限、跨账号会话隔离以及并发管理员降级保护。浏览器验证使用隔离数据，检查桌面和移动端、深浅色与中英文显示，以及账号创建、二次验密失败、最后管理员保护和会话注销交互。会话失效后，同账号重登保留未保存内容，切换账号清空前一账号编辑状态，只读账号不显示写入入口。
